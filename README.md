# Secure Auth System PRO (PHP + MySQL)

A complete and secure user authentication system built with **PHP**, **MySQL**, **HTML/CSS**, and **JavaScript**.  
This PRO version includes advanced features like **email verification, password reset system, user roles, admin dashboard, activity logs**, and more.

Perfect for developers, students, and freelancers who want a ready-made authentication template or a starter kit for bigger projects.

---

## 🚀 Features

### 🔐 Authentication
- User Registration  
- Secure Login  
- Logout system  
- Password Hashing (BCRYPT)  
- Email Verification Link  
- Password Reset via Email  
- Login Rate-Limiting (basic protection)  

### 👤 User Features
- Profile Page  
- Update Profile Info  
- Change Password  
- Email Verified Status  
- Modern UI Components  

### 🛡 Admin Features
- Admin Dashboard  
- View All Users  
- Delete / Ban Users  
- Activity Logs (login, reset, updates)  
- Verification Status Control  

### 📦 Technical Features
- Organized folder structure  
- Prepared for production  
- Clean, readable PHP code  
- Reusable functions (functions.php)  
- Token-based email verification  
- Secure session handling  
- Easy to integrate into any PHP system
